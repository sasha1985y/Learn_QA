MAIBENBEN Ubuntu 22.04.5 LTS

Разберу подробно, как получить сведения о системе в Ubuntu 22.04 — сгруппировал команды по категориям.


## 1. Общая информация о дистрибутиве

**Способ 1. Команда `lsb_release`**
```bash
lsb_release -a
```
Вывод:
```
No LSB modules are available.
Distributor ID: Ubuntu
Description:    Ubuntu 22.04.3 LTS
Release:        22.04
Codename:       jammy
```

**Способ 2. Просмотр файла `/etc/os-release`**
```bash
cat /etc/os-release
```
Показывает подробную информацию: версия, кодовое имя, идентификатор и т. д.

**Способ 3. Команда `hostnamectl`**
```bash
hostnamectl
```
Выводит версию ОС, ядра, архитектуру и время работы системы.

**Способ 4. Файл `/etc/issue`**
```bash
cat /etc/issue
```
Краткий вывод версии Ubuntu (часто используется в минималистичных установках).

**Графический способ:**
1. Откройте «Настройки» → «О системе».
2. В разделе «Подробности» увидите версию Ubuntu и другую базовую информацию.

## 2. Информация о ядре

**Способ 1. Команда `uname`**
* Только версия ядра:
```bash
uname -r
```
Пример вывода: `5.15.0-84-generic`
* Полная информация о ядре:
```bash
uname -a
```

**Способ 2. Файл `/proc/version`**
```bash
cat /proc/version
```
Показывает детали компиляции ядра и дату сборки.

## 3. Аппаратная информация

**Процессор:**
```bash
lscpu
```
Даёт подробную информацию о CPU: модель, количество ядер, потоков, частоту и т. д.

**Оперативная память:**
```bash
free -h
```
Отображает объём RAM и swap в удобном формате (ГБ/МБ).

**Диски и разделы:**
* Список дисков:
```bash
lsblk
```
* Подробная информация о разделах:
```bash
fdisk -l
```
(нужны права `sudo`)

**Графическая карта:**
```bash
lspci | grep -i vga
```
Или для более детальной информации:
```bash
sudo lshw -C display
```

**Сеть:**
* IP‑адреса и интерфейсы:
```bash
ip a
```
* Информация о сетевых картах:
```bash
lshw -C network
```

## 4. Программное обеспечение

**Установленные пакеты:**
* Общее количество:
```bash
dpkg --get-selections | wc -l
```
* Поиск конкретного пакета:
```bash
apt list --installed | grep имя_пакета
```

**Версия менеджера пакетов:**
```bash
apt --version
```

## 5. Системные ресурсы в реальном времени

**Использование CPU и памяти:**
```bash
top
```
или более современный вариант:
```bash
htop
```
(может потребовать установки: `sudo apt install htop`)

**Загрузка системы:**
```bash
uptime
```
Показывает время работы системы и среднюю загрузку за последние 1, 5 и 15 минут.

## 6. Дата и время

**Текущая дата и время:**
```bash
date
```
**Часовой пояс:**
```bash
timedatectl
```

## Краткий справочник команд

| Что нужно узнать | Команда |
|--------------|--------|
| Версия Ubuntu | `lsb_release -a` или `cat /etc/os-release` |
| Версия ядра | `uname -r` |
| Информация о CPU | `lscpu` |
| Использование памяти | `free -h` |
| Диски и разделы | `lsblk` или `fdisk -l` |
| Сетевые интерфейсы | `ip a` |
| Графическая карта | `lspci \| grep -i vga` |
| Загрузка системы | `uptime` |
| Процессы в реальном времени | `top` или `htop` |
